Entry for the [Two-Sentence Horror](https://make.fun/c/u-suroto-two-sentence-horror-acea9253)
competition on make.fun: one original horror story in exactly two sentences.

`main.ts` (Node 22, standard library only, no network) writes the story to
`/output/entry.txt`. Run locally with `MAKEFUN_OUTPUT_DIR` set to override
the output directory.
